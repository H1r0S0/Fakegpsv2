# Fake GPS (Android)

Приложение для подмены местоположения. Найди адрес или коснись карты, нажми «Перенести меня сюда», и все приложения увидят новое место.

## Возможности
- Поиск по адресу или названию места (геокодер Android).
- Карта: схема или спутник (MapLibre + подложка Esri).
- Метку можно перетаскивать пальцем.
- Недавние места.
- Пошаговая настройка телефона с проверкой каждого шага.
- Уведомление с кнопкой «Стоп», пока подмена включена.

## Сборка
APK собирается автоматически через GitHub Actions (вкладка Actions → Artifacts → FakeGPS-apk).

## Важно
Банки, Pokémon GO и похожие приложения замечают подмену и могут заблокировать аккаунт.
